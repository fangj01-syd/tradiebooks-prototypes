# TradieBooks Prototypes

UI prototypes for **TradieBooks** — a mobile-first accounting app designed for Australian solo tradies.

## What's included

- Core Version 1 flows (invoice, receipt, BAS, year-end)
- Payment closed-loop screens
- English interface mockups
- HTML gallery page (`index.html`)

## Current status

Design prototypes ~70-80% complete.  
No functional app code yet.

## How to view

Open `index.html` in a browser (images expected under `rendered/` folder).
